# Security model

LXReview deliberately runs its dedicated Claude worker with bypass permissions. It does not change permission mode in ordinary Claude conversations.

Workers have an explicit tool list, no subagent tools, no external MCP servers, and run-scoped `PreToolUse` hooks. Hooks block compound shell commands, shell expansion, arbitrary interpreters, force pushes, destructive Git operations, remote changes, hook bypass, credential paths and writes outside the selected repository. Evaluation is read-only. Edit/test turns cannot write Git metadata or access the network. Only a separate Git publication turn can stage, commit and push after tests pass. Push policy checks reject force/mirror refspecs and alternate destinations in Git configuration; normal pushes use the existing upstream only. Claude's Bash sandbox is explicitly enabled with `failIfUnavailable` and no unsandboxed fallback. Browser/bridge credentials are denied to sandboxed tools. Missing sandbox prerequisites must fail rather than weaken the policy.

These protections are defense in depth, not a claim that hooks safely execute arbitrary hostile projects. Test code and Git hooks are executable code; use a disposable branch and trusted repository. Only the publication turn may read Git identity and HTTPS credential-helper files (`~/.gitconfig`, `~/.config/git`, `~/.git-credentials`, `~/.config/gh`), and its hook still limits Bash to status/diff/log/show/add/commit/plain push. SSH remotes are not expected to authenticate: `~/.ssh` stays unreadable and the Linux sandbox blocks agent sockets. Use an HTTPS remote with a credential helper. A failing push is never fixed by disabling the sandbox. The initial test-command allowlist supports pytest and basic repository inspection; other build systems need a reviewed policy extension. User or enterprise Claude managed settings may further restrict operation.

Playwright drives Chrome over a private pipe, so Chrome opens no debugging port. The browser service accepts calls only on a 0600 unix socket inside the private installation root, with a per-start bearer token. VNC and the relay bind only to loopback. SSH reverse forwarding explicitly binds `127.0.0.1` on the exact LXPLUS node. Loopback is not a user boundary: relay bearer authentication remains mandatory. A fresh challenge checks server possession of the relay token before the client sends its bearer to a potentially stale port. Pairing uses a single-use ten-minute nonce. Relay credentials rotate on bridge creation, expire after at most eight hours, and are sent over SSH stdin, never argv. A disconnected bridge is unavailable, and credentials expire even when remote cleanup cannot run. The relay accepts only named package operations and no arbitrary URL or file proxying.

Private roots/directories use 0700 and secrets/state use 0600. Runtime archives are pinned by SHA-256 and Python dependencies by `uv.lock` hashes; Playwright never downloads browsers. Downloads are staged and checked before extraction. Browser state is never copied, exported or shared. No OpenAI API, cookie extraction, CAPTCHA bypass, or MFA bypass exists.

Events redact credential-shaped keys/values and drop thinking/signature blocks. Raw reviewer responses are preserved verbatim by contract, so do not send credentials to the reviewer. Audit artifacts may contain proprietary code and should be handled as private repository data. The package cannot reliably recognize every arbitrary secret embedded in source text; inspect reports before sharing them.

Installer integration refuses command collisions. Uninstall removes only registrations and links that still match ownership records. It archives the private root for recovery; delete the archive for complete removal. No shell startup, conda, global npm, user VNC startup or unrelated browser process is modified.
